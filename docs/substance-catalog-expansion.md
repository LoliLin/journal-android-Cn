# 精神活性物质目录扩充与代谢资料

本轮资料核对日期：2026-09-08。内置目录从 291 条增加到 865 条，新增 574 条。范围同时包括精神科医用药物、研究化学品、娱乐性物质及部分植物和真菌材料。

“所有精神活性物质”没有固定、完整且持续有效的全球清单。本轮采用可审计的来源快照，不能据此宣称已收录世界上每一种物质，也不能把目录收录视为上市许可或治疗建议。

## 覆盖来源

| 新增条目的首要来源 | 数量 | 使用方式 |
| --- | ---: | --- |
| WHO 协作中心 ATC 索引 | 332 | 收录单一成分；包含历史用药，不推断现行获批状态 |
| TripSit 物质资料库 | 225 | 核对名称和别名，映射分类，排除明确不适用或资料冲突的记录 |
| PsychonautWiki | 10 | 逐项选择具体物质，不直接导入分类页及错误元数据 |
| EUDA | 7 | 补充部分合成阿片、大麻素及卡西酮条目 |

ATC 核对范围为 N05、N06、N03A、N02A、N07B、A08AA、C02AC、N04AA、N04BD。覆盖抗精神病、抗抑郁、抗焦虑、催眠镇静、ADHD、抗癫痫、部分心境稳定、认知障碍、成瘾治疗及相关中枢药物。抗癫痫药没有一律标记为心境稳定剂，非兴奋剂 ADHD 用药也没有一律标记为兴奋剂。

来源入口：[ATC 索引](https://atcddd.fhi.no/atc_ddd_index/)、[TripSit 数据库](https://github.com/TripSit/drugs)、[PsychonautWiki API](https://api.psychonautwiki.org/)、[EUDA 2026 新精神活性物质资料](https://www.euda.europa.eu/publications/european-drug-report/2026/new-psychoactive-substances_en)。逐条来源、规范名称对应和排除理由见 [substance-catalog-expansion.json](substance-catalog-expansion.json)。

## 名称与本地化

- `root` 保留稳定的英文名称作为记录键。短名、通用名及已核实的商品名作为搜索别名，不因大小写、连字符或别名另造记录。
- 新增条目均提供英文、简体、繁体介绍。289 条新增记录提供中文显示名；其余较少见药物或研究代号保留原名，避免编造中文通用名。
- 本轮没有翻译大段来源文章，介绍和代谢文字是简要整理；原文可通过来源链接查阅。PsychonautWiki 原内容依其 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 标示保留来源归属。
- 植物、真菌及其他多成分材料不能与某个分离活性成分的质量直接等同。盐型、前药、缓释及长效注射制剂也不能自动按相同数值换算。

## 代谢与排泄

详情页新增独立的“代谢与排泄”栏目和来源按钮。148 种物质具有本轮核实的具体描述，其中 119 条为新增记录，29 条为原有记录。

主要依据 DailyMed 药品说明书、EMA 产品资料、厂商发布的 SmPC、CPIC 指南，以及部分研究化学品的原始研究。逐条链接、证据类型和可用的说明书日期见 [substance-metabolism-sources.json](substance-metabolism-sources.json)。

记录时区分以下情况：

- **CYP 氧化代谢**：说明实际参与的酶、反应和有依据的代谢物，不把“抑制某酶”写成“由该酶代谢”。
- **非 CYP 途径**：例如葡萄糖醛酸化、酯/酰胺水解、醛氧化酶及线粒体 β-氧化。
- **前药及活性代谢物**：例如赖氨苯丙胺由红细胞转化为右旋苯丙胺，利培酮形成帕利哌酮。
- **原形排泄**：例如锂、加巴喷丁、普瑞巴林，不能强行填入肝脏 CYP 途径。
- **证据限制**：体外人肝细胞、微粒体或病例样本结果按其证据类型叙述，不冒充完整的受控人体药代研究。

另外 455 条新增记录明确显示本条目代谢资料尚未核实；这是文档缺口，不代表科学界没有研究，也不代表物质不发生代谢。多成分材料单独说明无法套用单一成分代谢途径。没有依据时不推断酶、活性代谢物或排泄比例。

## 剂量、相互作用与数据格式

本轮不引入推荐剂量、娱乐性剂量分级、作用时长或推断的相互作用风险矩阵。ATC 的 DDD 是统计用指标，不能当成处方剂量或单次摄入量。给药途径仅采用来源中明确列出的、应用能够表示的途径；单位用于记录，不构成用量建议。

新条目保留 `isApproved: false`。该字段在现有应用中表示资料审核状态，不是药品的监管批准状态。新增风险文字明确说明：没有相互作用提示不等于已证明组合安全。

新增可选字段：

```json
{
  "metabolism": "Substance-specific metabolism and elimination text.",
  "metabolismSources": ["https://example.org/product-information"]
}
```

`metabolism` 是可翻译文本，简体和繁体覆盖层只覆盖文字。`metabolismSources` 放在根数据中，为来源 URL 数组。旧资产及扩展包省略这两个字段时继续正常加载，解析器保持宽容处理。

## 维护方式

直接修改对应 `root/<Name>.json` 和中文覆盖层，不需要运行抓取脚本或联网才能构建、搜索和记录。补充代谢资料时同时更新来源清单中的 `reviewed`/`notYetVerified`，保留“尚未核实”与“已知基本不代谢”的区别。

## 本轮验证

- `testDebugUnitTest`：45 个 JVM 测试通过；在现有解析测试中增加代谢文本与来源字段的保留检查。
- 按 `root → en_us → 当前语言` 合并后，校验全部 865 条物质的三语资产；实际 `SubstanceParser` 共成功解析 2,595 条语言版本，并验证英文、中文、拼音和别名搜索。
- 改动的 Kotlin 文件通过 ktlint 1.3.1，JSON 使用 Prettier 格式化，Debug APK 构建成功并核对打包内容。
- Android API 28 模拟器中核对新增药物搜索以及代谢栏目、来源按钮的显示；未修改日记记录。
