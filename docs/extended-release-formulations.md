# 口服缓释剂型记录

新增记录的确认页及已有记录的编辑页现在提供“剂型”选择。只有目录中配置了口服剂型的物质才显示；已有剂型标记的记录即使目录配置以后变化，仍可查看和清除该标记。

## 首批支持

阿普唑仑、安非他酮、卡马西平、可乐定、胍法辛、锂、哌甲酯、帕利哌酮、帕罗西汀、喹硫平、丙戊酸相关制剂、文拉法辛、唑吡坦，共 13 个品种。说明书来源见 [extended-release-formulations.json](extended-release-formulations.json)，核对日期为 2026-09-08。

可选值为：

- **未指定**：没有记录释放方式，旧记录保持这个状态。
- **普通 / 速释**：`IMMEDIATE_RELEASE`。
- **缓释 / 控释**：`EXTENDED_RELEASE`，作为 SR、ER、XR、CR 等标示的概括性记录。

帕利哌酮的口服选项只列“未指定”和“缓释 / 控释”。剂型依据实际包装记录；仅有肠溶包衣不代表缓释。此选项不换算剂量，也不保证不同品牌、盐型和释放系统可按相同毫克数互换。

## 保存及回溯

- Room 数据库从 v7 自动迁移到 v8，为 `Ingestion` 添加可空 `releaseForm` 文本列。旧数据不被推断为普通片。
- 日记记录行显示已指定的剂型，编辑时保留选择。
- 最近使用的快捷剂量包含剂型，因此相同物质、相同剂量的普通和缓释记录不会合并为同一个快捷项；再次使用快捷项会带入原剂型。
- 导出 / 导入使用可选 `releaseForm` 字段。旧备份省略该字段时按“未指定”读取。
- 当前没有剂型专用的剂量和时长数据，缓释记录不采用普通制剂的剂量分级、相对剂量参考或作用时间曲线；记录中的实际剂量和摄入时间仍保留。

## 目录格式

在对应 `root/<Name>.json` 添加结构字段，不需要在中文覆盖层复制：

```json
{
  "oralReleaseForms": ["IMMEDIATE_RELEASE", "EXTENDED_RELEASE"]
}
```

未配置时默认为空列表。解析器忽略无法识别的剂型值，继续保持宽容加载；该配置仅用于口服路线。

## 验证

- 46 个 JVM 测试通过，包括目录字段解析和通过实际导入导出映射进行的剂型备份往返。
- Debug APK 构建成功，确认包含 13 个品种的剂型配置。
- Android API 28 模拟器验证 v7→v8 迁移：旧记录剂型为 `NULL`，原剂量及单位保留。
- 实测新增缓释记录、编辑为普通剂型，以及同剂量两种剂型的快捷记录区分与选择恢复。
- 验证后已还原测试前的日记数据库，并再次确认自动升级后的记录数量与测试前一致。
